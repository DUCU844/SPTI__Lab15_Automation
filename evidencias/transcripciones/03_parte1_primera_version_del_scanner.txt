===== Parte 1 C - CLI con argparse (scanner.py) =====
kali@kali:~/lab15$ python3 scanner.py --help
usage: scanner.py [-h] [--ports PORTS] [--rate RATE] [--timeout TIMEOUT]
                  [--output OUTPUT] [--jitter JITTER] [--retry-errors]
                  [--scope SCOPE]
                  target

Concurrent TCP connect port scanner (asyncio). Scan only hosts you are
authorized to scan.

positional arguments:
  target             IP address to scan

options:
  -h, --help         show this help message and exit
  --ports PORTS      port range, e.g. 1-1024 or 22,80,443 (default: 1-1024)
  --rate RATE        max concurrent connections (default: 200)
  --timeout TIMEOUT  per-port timeout in seconds (default: 0.5)
  --output OUTPUT    JSON output file (default: stdout)
  --jitter JITTER    max random delay in seconds before each probe (default:
                     0, no jitter)
  --retry-errors     re-scan ports whose probe failed with an OS error at low
                     concurrency (rate 50)
  --scope SCOPE      scope file; refuse to scan unless the target and the
                     current time are authorized
